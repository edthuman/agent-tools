# Agent Tools

This is a repository for me to store skills and scripts that I find useful when working with agents.

I created the tools in this repo for my own use personally and professionally, so they are tailored to work with my own agent setup and choice of agent provider.

### How I use agents

At the time of creating this repo, I am currently only subscribed to Claude Code, having liked using it in my most recent job. I am actively trying out the free tier of other AI coding agents, but have not yet been convinced to switch to another provider.

I run Claude Code in a separate terminal app from my IDE as I personally feel it:
- avoids some performance issues
- allows me to more easily position sessions in different areas of the screen
- allows tools to affect sessions visually more easily, e.g. changing their background colour

## Getting started
To begin using these tools, please clone this repo, using command:

git clone https://github.com/edthuman/agent-tools.git
